# OpenSim walking clip

`opensim-walk.json` is generated by `scripts/export-behind-glass-opensim.py` using OpenSim 4.6. Run `uv run scripts/export-behind-glass-opensim.py` to regenerate (Python 3.11–3.13).

Source: [OpenSim's distributed Gait2392 model and example pipeline](https://github.com/opensim-org/opensim-models/tree/d9b05d470b1a481c222372c85b75772faf8f7792/Pipelines/Gait2392_Simbody). Authors and scientific references: [Gait2392 documentation](https://opensimconfluence.atlassian.net/wiki/spaces/OpenSim/pages/53086215/Gait+2392+and+2354+Models).

- Model: `OutputReference/subject01_simbody_adjusted.osim`.
- Trajectory: `OutputReference/ResultsCMC/subject01_walk1_Kinematics_q.sto`, the distributed computed-muscle-control (CMC) result, not a new forward simulation run by this project.
- Exact upstream revision, SHA-256 hashes, OpenSim version and extraction interval are embedded in the JSON.
- Rotational columns are degrees despite the legacy `.sto` header saying `inDegrees=no`: the corresponding pipeline Kinematics analysis uses `in_degrees=true` and its companion `.mot` carries the same numeric values.
- Six-harmonic periodic fitting of the 0.60–1.83 s trajectory closes the display loop. OpenSim realizes the fitted coordinates on the source model, including coupled knee translations. These are then baked into 160 samples containing bilateral hip, knee, ankle and heel/toe stations.
- Drawing units: 120 per metre. A 1.1 m/s treadmill compensation supplies display travel. The foot-bottom stations (calcaneus-local `[0,-.035,0]` and `[.20,-.035,0]`) approximate a shoe sole; no source bone meshes are distributed.
- Browser interpolation, blur, camera projection, loop fitting, standing blend, timing changes and shoe shape are presentation choices. This is not a clinical simulation or a real-time muscle-force solver.
- Only walkers use the OpenSim clip. The previously added procedural runner is retained unchanged.

OpenSim's documentation attributes the model to Thelen, Seth, Anderson and Delp, and the accompanying experimental protocol to John et al. (2012), DOI 10.1080/10255842.2011.627560. Upstream distribution/provenance is retained here; no new license grant is asserted for the source data.
