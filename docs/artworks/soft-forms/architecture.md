# 솜결 아키텍처

솜결은 솜털로 덮인 캐릭터의 눌림·회전·확대를 구현한 3D 작품이다. 시스템은 화면 입력에서 접촉점을 산출하고, 기준점으로 몸체를 변형한 뒤, 변형된 표면에 셸과 리본을 배치해 털을 표현한다.

이 문서는 접촉점 산출, 몸체 변형, 털의 구성과 부착, 프레임 처리 순서로 동작 원리를 설명한다. [웹 문서](./index.html)의 데모는 각 단계의 입력과 결과를 표시한다.

## 1. 입력 처리와 접촉점 산출

터치 입력은 화면의 가로·세로 좌표를 전달한다. 몸체의 눌림을 계산하려면 이 좌표에 대응하는 3D 표면 위치가 필요하다.

접촉 검사는 **화면 입력 위치를 통과하는 광선과 몸체 표면의 첫 교점**을 구한다. 카메라의 시선 방향을 기준으로 교점을 찾는 레이캐스팅(ray casting)을 사용하며, 처리 순서는 다음과 같다.

1. 입력 좌표를 작품 화면 안의 상대 위치로 변환한다.
2. 현재 카메라를 기준으로 해당 위치를 통과하는 광선을 생성한다.
3. 변형된 몸체와 광선의 교점 중 카메라에 가장 가까운 점을 선택한다. 교점이 없으면 접촉 반응을 시작하지 않는다.
4. 접촉 위치와 표면의 방향인 법선을 저장한다.

접촉 위치는 캐릭터의 로컬 좌표로 변환한다. 이 좌표는 캐릭터 자체를 기준으로 하므로, 화면에서의 배치·회전과 몸체 안의 접촉 위치를 분리할 수 있다. 법선은 표면의 바깥 방향을 나타내며, 눌림은 그 반대인 안쪽 방향으로 적용한다.

검사 대상은 몸체 표면이다. 개별 털을 검사하는 비용을 줄이고, 동일한 접촉 위치와 법선을 몸체·털의 반응 계산에 전달한다.

데모는 정면의 입력 위치와 측면의 광선 경로를 함께 표시한다. 몸체의 가운데·옆면에서는 접촉점이 생성되고, 몸체 밖에서는 광선만 표시된다.

## 2. 몸체 형상과 변형

몸체는 삼각형으로 구성된 구 메시에서 생성한다. 구 표면의 각 점을 캐릭터의 외곽선과 깊이에 맞춰 이동해 기준 형상을 만든다.

몸체의 연속적인 변형을 제어하기 위해 중심에 하나, 둘레에 열두 개의 **변형 기준점**을 배치한다. 각 기준점은 독립적으로 이동·회전하며, 주변 표면점은 여러 기준점의 영향을 나눠 받는다.

영향의 크기는 표면점과 기준점 사이의 거리로 정한다. 가까운 기준점의 영향은 크고, 먼 기준점의 영향은 작다. 따라서 기준점 하나의 이동은 주변 표면에 집중되고, 거리가 멀어질수록 약해진다.

데모는 실제 변형 계산을 적용한 별 모양 몸체의 정면 단면이다. 기준점을 이동하면 원래 외곽선과 변형된 외곽선의 차이가 표시된다.

각 표면점의 최종 위치는 기준점별 변형 결과를 가중 합산해 구한다. 먼저 거리로 계산한 영향을 전체 영향의 합으로 나눠 가중치의 합을 1로 맞춘다. 이어 각 기준점의 이동·회전을 적용한 위치에 해당 가중치를 곱하고, 결과를 모두 더한다.

```text
기준점별 가중치 = 해당 기준점의 영향 ÷ 모든 기준점 영향의 합
최종 위치 = 모든 기준점의 (변형을 적용한 위치 × 가중치)를 더한 값
```

가중치는 기준 형상에서 한 번 계산해 저장하고, 매 프레임에는 기준점의 변형 상태를 갱신한다. 데모는 이동만 조작하며, 실제 자동 움직임에는 회전도 포함된다.

여러 기준점의 결과를 함께 사용하는 목적은 변형 영역의 경계에서 급격한 꺾임을 줄이는 것이다. 이웃한 표면점들의 가중치가 연속적으로 달라지므로, 기준점의 움직임도 표면을 따라 점진적으로 전달된다.

자동 움직임은 시간에 따른 기준점의 이동·회전으로 생성한다. 원본 캐릭터는 사전에 측정한 외곽선 움직임을 재생한다. 다른 캐릭터는 위치별 시간차를 둔 바람 형태의 움직임을 계산한다.

### 접촉에 따른 국소 변형

접촉 반응은 자동 움직임으로 변형된 몸체에 추가한다. 접촉점으로부터의 3D 거리에 따라 이동량을 줄이고, 저장된 법선의 안쪽 방향으로 표면을 이동시킨다. 이 처리로 접촉 주변에 눌림이 집중된다.

접촉을 유지하면 눌림이 점차 커지고, 접촉이 해제되면 눌림이 줄어들면서 반동이 발생한다. 반동의 도착 시점은 접촉점에서 멀수록 늦어져 바깥 방향으로 전파된다.

입력 동작에 따라 제어 대상도 구분한다. 누르기는 국소 변형, 드래그는 캐릭터 전체의 회전, 두 손가락의 벌림·모음은 카메라 확대 배율을 제어한다.

## 3. 털 표면의 구성

털 표현에는 몸체 밖의 부피와 외곽에 보이는 개별 가닥이 필요하다. 솜결은 **셸로 부피를 채우고, 리본으로 개별 가닥을 구성**한다.

![몸체 밖에 겹친 셸과 뿌리에서 끝으로 좁아지는 리본](../../assets/fur-shells-and-ribbons.svg)

데모는 몸체, 셸, 리본을 순서대로 표시한다. 셸 단계에서는 몸체 밖에 두께가 생기고, 리본 단계에서는 외곽에 개별 가닥이 추가된다. 작품과 동일한 몸체 계산과 셸·리본 셰이더를 사용하며, 회전 시 측면의 구성도 표시한다.

### 셸에 의한 부피 표현

셸(shell)은 몸체 표면을 복제해 바깥으로 이동시킨 얇은 층이다. 여러 층을 겹쳐 몸체 밖에 색과 두께를 형성한다.

각 층에는 불규칙한 무늬로 빈 영역과 채워진 영역을 만든다. 안쪽 층은 밀도를 높이고, 바깥쪽 층은 밀도와 불투명도를 낮춘다. 층 사이로 내부가 보이는 구조를 통해 중심부의 밀도와 가장자리의 성긴 표면을 함께 표현한다.

층의 간격은 두께가 분포하는 위치를 결정한다. 안쪽 간격이 좁으면 몸체 가까이에 층이 집중된다. 데모의 각 곡선은 셸 한 층의 단면이며, 배치 밀도를 변경하면 층 사이의 간격이 갱신된다.

### 리본에 의한 개별 가닥 표현

리본(ribbon)은 뿌리와 끝을 잇는 가늘고 긴 띠다. 폭은 뿌리에서 끝으로 갈수록 좁아지고, 중심 경로에는 휨을 적용한다. 가닥별 길이와 기울기에 차이를 두어 외곽선에 변화를 만든다.

시점 변화에 따른 가닥의 가시성을 유지하기 위해 리본의 폭 방향을 화면에서 결정한다. 뿌리와 끝을 화면에 투영한 뒤, **투영된 가닥 방향에 수직으로 폭을 펼친다.** 이 처리로 캐릭터가 회전해도 띠의 넓은 면이 카메라를 향한다.

가닥의 길이 방향이 카메라를 향하면 화면에 투영된 길이는 짧아진다. 이때도 셸이 가닥 사이의 부피를 유지한다.

## 4. 털의 부착과 접촉 반응

몸체와 털의 위치 관계를 유지하기 위해 **표면의 변형 가중치를 털에도 적용**한다. 초기화 시 각 가닥의 뿌리 위치와 기준점별 가중치를 저장하고, 몸체가 변형될 때 동일한 기준점의 이동·회전을 적용한다.

한 가닥의 뿌리와 끝은 같은 가중치를 사용한다. 이 결합으로 몸체 변형에 따른 가닥의 과도한 늘어남과 꺾임을 줄인다. 셸도 매 프레임 변형된 몸체 표면을 기준으로 배치한다.

### 뿌리와 끝의 이동량

접촉 반응은 몸체와 털에 같은 접촉 위치·법선을 사용한다. 접촉점에서 각 점까지의 3D 거리와 접촉 유지 시간으로 눌림 크기를 구하고, 법선의 안쪽 방향으로 이동량을 계산한다.

몸체와 털 뿌리에는 계산된 이동량을 적용하고, 털끝에는 뿌리 이동량의 72%를 적용한다. 뿌리와 끝의 이동량 차이는 가닥의 길이와 기울기 변화로 나타난다.

데모는 몸체의 측면 단면을 확대한 것이다. 누르기와 해제에 따른 뿌리·끝의 위치를 표시하며, 수치는 작품 좌표에서의 이동 거리다.

<!-- interactive-demo: binding -->

접촉 해제 후에는 각 점까지의 거리를 파동 속도로 나눠 반동의 도착 지연을 구한다. 도착 시점에 짧게 증가했다가 감소하는 이동량을 더해 반동을 전파한다. 드래그 중에는 털끝에 이동 방향의 뒤쪽으로 남는 기울기를 추가한다. 뿌리의 부착을 유지하면서 끝의 반응을 별도로 조절하는 구조다.

## 5. 프레임 처리와 화면 출력

매 프레임의 처리 순서는 다음과 같다.

1. 시간에 따른 기준점의 이동·회전과 현재 접촉 상태를 갱신한다.
2. 기준점별 가중치로 몸체를 변형하고 접촉에 따른 국소 이동을 적용한다.
3. 변형된 몸체에 맞춰 셸과 리본의 위치를 갱신한다.
4. 배경·몸체·셸·리본·눈을 정해진 순서로 렌더링한다.

몸체와 털은 같은 표면색을 사용해 색의 연속성을 유지한다. 표면 방향에 따른 밝기 차이와 바닥 그림자로 입체감을 표현하고, 최종 화면에 약한 흐림을 적용해 가닥의 경계를 완화한다.

## 6. 검증과 구현 범위

검증 대상은 입력과 형상 변화의 대응, 몸체와 털의 결합, 털의 부피와 가닥 표현이다. 접촉 주변에 눌림이 집중되는지, 회전·변형 중에도 털의 뿌리가 표면을 따라가는지, 외곽의 가닥과 내부의 밀도가 함께 유지되는지 확인한다.

현재 구현은 셸·리본·접촉 반응을 결합해 솜털의 외관과 움직임을 구성한다. 털 사이의 충돌과 섬유 내부의 빛 산란은 계산 범위에 포함하지 않는다.
